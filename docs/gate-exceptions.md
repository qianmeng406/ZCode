# 门禁豁免记录

只有经过批准的例外才写在这里，并在失效后删除。模板：

```text
## EX-YYYY-NNN

- 规则：GATE-<ID>（例如 GATE-SECRET / GATE-UNIT-STRONG）
- PR / 分支：<链接或分支名>
- 提交 SHA：<完整 sha>
- 原因：<为什么必须现在合并>
- 范围：<仅限哪些文件/检查>
- 批准人：<姓名或账号>
- 创建时间：YYYY-MM-DD
- 失效时间：YYYY-MM-DD
- 后续动作：<修复计划与复核时间>
```

约定：

- 豁免不改变本地门禁行为；需要放宽推送范围时使用 `ZCODE_GATE_SCOPE=package|full`，这只会**增加**检查。
- CI 中需要豁免时必须走仓库管理员的 Rulesets 绕过流程，并在本文件登记。
- 密钥泄露类问题不允许豁免，只能撤销凭据并清理历史。
